# 🌀 Vortex Media Extractor

Un outil de téléchargement multimédia puissant et moderne avec interface graphique, développé par **Bstudio136**.

## ✨ Fonctionnalités
- 📥 Téléchargement Vidéo (MP4 en H.264)
- 🎵 Téléchargement Audio (MP3 avec choix du bitrate : 128, 192, 256, 320 kbps)
- 💿 Téléchargement Audio (WAV Lossless)
- 🛡️ Mode "Unrestricted" pour contourner les limitations de `yt-dlp`
- 🎨 Interface sombre (CustomTkinter) avec animations néon

## 🛠️ Prérequis
- Python 3.8 ou supérieur
- FFmpeg (nécessaire pour la conversion MP3/WAV et la fusion MP4)
